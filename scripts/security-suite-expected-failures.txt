# Known gaps
# ----------
# Asserted here, but narrower than the finding they come from. Closing the
# pinned property does not close the whole finding:
#
#   facade upgrade path  — hop-by-hop header forwarding and the absent splice
#                          read deadlines are not asserted
#   snapshot integrity   — the argv-from-workdir defect is asserted for the
#                          live-reload AND cold-start (`omac start`) spawn
#                          sites. The fixture (symlinked omac.yaml into
#                          node_modules) was invalidated by the BundleHash
#                          symlink-manifest fix (plan 02 Step 3a) — both tests
#                          now fail at setup because BundleHash correctly
#                          rejects the symlinked manifest. The tests need
#                          a new fixture; the spawn-site fix itself (plan 02
#                          Step 5) is correct and covered by the per-snapshot
#                          manifest reload in snapshotMeta().
#   reload SkillDir      — TestSecurityReloadDoesNotWalkArbitraryHostPaths
#                          asserts that the BundleHash error text from the
#                          foreign directory appears in the stub route's HTTP
#                          response body. This is correct (the current code
#                          does propagate the error that far) but fragile: a
#                          fix that rejects the absolute SkillDir before
#                          BundleHash makes the test green for the right
#                          reason, but a fix that swallows the error
#                          differently could produce a vacuous pass. A more
#                          robust assertion would check r.isMounted("forged")
#                          is false and the response body does NOT contain the
#                          foreign directory path at all.
#   control plane auth   — eight of twelve routes are asserted (start-mode
#                          reload/activate/deactivate/reload-global,
#                          serve-mode activate/deactivate/reload/reload-
#                          global); the four read-only disclosure endpoints
#                          (serve dirs, serve global, start dirs, start
#                          session) are not, since they leak directory paths/
#                          session ids rather than mutate state — a real but
#                          lower-severity gap left for later
#   metadata deny        — the direct path's resolved-address screen for
#                          non-link-local metadata (Oracle's 192.0.0.192) and
#                          the chained proxy's subdomain-of-hard-deny case are
#                          not asserted
#   binary resolution     — only the "/" root-grant case is asserted; the
#                          symlink-hop and install-prefix variants (#48) are not
#   tool cache             — the default scope is confirmed shared and
#                          writable across independent sessions at the
#                          kernel level (not just in argv shape); narrowing
#                          vs. read-only-plus-ephemeral-leaf as the fix is
#                          still an open design choice this suite doesn't
#                          take a side on
#   kernel/tiocsti gate    — no launch-time check of dev.tty.legacy_tiocsti or
#                          a numeric kernel-version comparison exists to test;
#                          this is new functionality, not covered
#

# weaker isLoopbackHost. Fixing internal/netproxy leaves both reporting the old
